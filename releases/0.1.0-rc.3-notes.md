# Fairway XMP 0.1.0-rc.3

Draft notes for the next release candidate. No candidate installer or device acceptance has been recorded, and this version is not published.

## Changes since RC 2

- View row has a dedicated reading layout with full wrapped text, field metadata, clear NULL/empty markers, per-field copy and Copy row JSON. Edit remains available for writable keyed rows.

- A compact terminal toolbar keeps tabs, new-terminal folders, External terminal and maximize together. Type `exit` to start a fresh first terminal or close the extra tab. The embedded prompt shows a green arrow and current folder; Windows uses its full current path. Terminal sizing keeps the current input line inside the card.
- External terminal opens the active shell's current folder, including after `cd`. No scripts, shell commands, prompt changes or tool-path overrides are injected. Fairway CLI availability follows Settings → Command-line tools.
- Terminal, Logs, Mail and Data browser can maximize inside the app window. Background controls are inactive, nested dialogs keep their focus, and restoring retains the same workspace. Escape restores most views; terminal input keeps Escape for shell programs and uses Cmd/Ctrl+Shift+M to restore.
- Logs adds Clear view without changing log files and a visible Open log folder action. Repeated service failures remain visible after an observed recovery or message change. Filters, pause and copy share a compact menu; Live/Paused appears beside the title.
- MySQL SQL-file import is available through Database actions. Type the target name to confirm. A complete target backup must succeed before SQL runs. The dialog shows backup/import/cancellation phases, failures include the backup path, and the catalog refreshes after partial changes. Completed statements cannot be undone by Cancel. SQL can affect other schemas; only the selected target is backed up automatically.
- SQL results report rows inserted, deleted or returned. MySQL UPDATE reports changed rows, including zero for unchanged values; SQLite says rows matched for update because its count includes unchanged matches. Single results omit the redundant Result 1 label.
- MySQL remembers the selected database/table during the app session, including source switches. Nullable row fields accept typing directly. Open backups stays visible at the bottom right, separately from Open SQLite file. SQLite retains file backups without SQL-file import/export.
- Page descriptions use short operational language. Fast TypeScript regressions run in verification/candidate builds; native test coverage includes import cancellation, progress events, query counts and external-terminal folder resolution.
- PHP 8.0 and 8.1 are no longer included on Windows, macOS, or Linux. PHP 8.2 through 8.5 remain, and PHP 8.5 stays the default. A saved 8.0 or 8.1 selection is kept and blocks service startup until the user chooses PHP 8.2 or later.

- Create table and Structure include a Foreign keys modal with labeled, copyable SQL examples. Structure opens the actual Table SQL in a copyable modal beside + Column, and the empty outgoing-reference message distinguishes it from incoming references. Redundant MySQL CLI examples are removed.
- Mail previews display inline attachment images and open HTTP/HTTPS links in the external browser. Email scripts and forms stay blocked, and keyboard navigation works within maximized Mail.
- A removed PHP selection can be replaced in Settings or with the Linux PHP-version command. Failed recovery saves preserve the previous selection, generated configuration and launchers. Runtime verification rejects stale manifests and leftover PHP directories.

- Update every bundled PHP branch to the October 21 security releases addressing CVE-2026-109618 and CVE-2026-109619.

## Installation, acceptance and retained limits

These notes do not authorize publication or mark acceptance complete. Build a new signed cross-platform candidate, verify its exact artifacts, and test RC 2 upgrades with existing work. Recheck SQLite protected-folder access in the signed Mac app; the local unsigned build cannot establish distribution permission behavior. Test the new layouts and keyboard/focus behavior in native WebViews at normal and minimum window sizes.

PHP 8.2.35, 8.3.36, 8.4.27 and 8.5.12 fix CVE-2026-109618 and CVE-2026-109619. The default stays PHP 8.5. Windows x64 NTS packages, macOS ARM bottles and Linux source inputs are pinned to these releases; see the [PHP update checklist](../docs/rc3-php-security-update.md) for verification and candidate status. SQLite files are edited in place and require their own backups; environment/update backups remain MySQL-only. Linux remains the terminal edition with manual updates. Windows Authenticode remains a disclosed RC limitation. Windows MySQL filesystem/code-page and non-ASCII CLI backup/export restrictions remain in effect. Mac Developer ID signing/notarization and cryptographic desktop updater signatures remain required.

See [Data browser](../docs/data-browser.md), [RC 3 review](../docs/rc3-readiness-review.md), and [candidate acceptance](../docs/beta-acceptance.md). Published RC 2 files and evidence remain unchanged.
