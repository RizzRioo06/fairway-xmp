# Fairway XMP 0.1.0 RC 1

Feature scope locked on 2026-10-18. Candidate source validation and exact-installer device acceptance are separate release gates.

## Included changes

- Built-in Mailpit mail catcher and searchable inbox, HTML/text previews, attachment saving, SMTP settings and Laravel configuration.
- Automatic PHP mail() integration. Default local inbox/SMTP ports are 8802 and 11025.
- Mail Start/Stop controls and status in the native Mac menu bar and Windows system tray.
- Old service ports survive an upgrade when they overlap the new mail defaults; only missing mail ports receive distinct values.
- Grouped sidebar: Environment, Terminal and Logs; Manage Sites, View Mail and Browse Data; Settings and Updates at the bottom.
- One global Logs page for troubleshooting, with problems shown first, source/search filters, live updates, pause and copy. The Site filter combines requests for one address with clearly labeled PHP output shared across all sites.
- Reliability fixes for backups with unusual database names, updates with no user databases, slow mail responses and incomplete attachments, special-character/long paths, and bounded CLI log reading.
- Signed RC update metadata and a separate update endpoint for future stable builds.

Per-site PHP is deferred. All sites use the global PHP version selected in Settings; PHP 8.0–8.5 remain bundled.

## Installation and updates

Mac: macOS 15+ on Apple Silicon. Windows: Windows 10 22H2 / Windows 11 x64. Linux: x86_64 with glibc 2.35+, terminal edition.

Beta 3 users can install manually, or through Updates after this exact RC is promoted to the preview feed. Beta 2 and earlier need a manual installation. Linux updates remain manual. Verify checksums and retain a database backup before upgrading. Exact-candidate acceptance must confirm preservation of projects, sites, settings and data before publication.

The Mac app/installer require Developer ID signing and Apple notarization. Mac/Windows updates require cryptographic signatures. Successful checks will be recorded against the exact published artifact hashes.

All other device checks and signed-updater CI precede publication. The human in-app update/restart check follows publication and feed promotion; published acceptance evidence identifies pending checks until the later test results are recorded.

## Known limitations accepted for this RC

- Windows installers have no Authenticode signature and may show unknown-publisher/SmartScreen prompts. Updater signatures remain required.
- PHP 8.0/8.1 remain unsupported legacy compatibility options. Their Windows dependency build/patch provenance remains unverified; existing inputs and collected sources are retained as-is. PHP 8.5 is the default.
- Windows MySQL requires ANSI-compatible paths or existing compatible short-name aliases; see the data-browser documentation.
- On Windows non-UTF-8 system locales, backup/export requires ASCII schema identifiers. A failed pre-update backup blocks installation and preserves data/services. Unicode row values remain supported. See [details](../docs/data-browser.md#windows-backupexport-identifiers).
- Linux updates are manual. ARM Linux, Alpine/musl and Intel Macs are outside the supported targets.
- Remote images stay blocked in the in-app mail preview; Open in browser offers Mailpit's full interface.

This is a prerelease. Report regressions with OS, build identity, reproduction steps and a reviewed diagnostic report. Omit credentials, database contents and private project files.
